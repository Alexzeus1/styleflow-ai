# StyleFlow AI

AI business manager for beauty professionals. Mobile-first Next.js MVP starter.

## Deploy fast

1. Create a Supabase project and run `supabase/schema.sql` in the SQL Editor.
2. Create a GitHub repo and push this project.
3. Import the repo into Vercel.
4. Add environment variables from `.env.example` in Vercel.
5. Deploy.
6. Add your custom domain in Vercel when ready.

## Integrations

- Supabase: database/auth
- OpenAI: AI assistant and marketing
- Paystack: Nigerian payments
- WhatsApp Business Platform: messaging

The UI currently uses realistic demo data. Connect Supabase and replace demo data with live queries before production customer use.

## Local

`npm install`
`npm run dev`

Open http://localhost:3000
